# 参数敏感性预实验记录（2026-11-12）

## 实验定位与复现

本报告只支持机制正确性、局部计算开销及短时敏感性分析。两个手写目标并非 FuzzBench/LAVA-M；不据此宣称参数最优、统计显著的覆盖率提升或正式漏洞发现能力。原始日志、源码和配置均保留在本目录。WSL Ubuntu 22.04；硬件、软件版本见 environment.json，端到端源码哈希见 source_hashes_v2.json。

运行：python3 validation/parameters/run_diagnostics.py；python3 validation/parameters/run_endtoend.py；python3 validation/parameters/analyze.py。端到端脚本拒绝覆盖已有目录，重跑需更换输出目录。

## 端到端短时预实验

## 实测结论

最终微基准在全部端到端fuzzer结束后重新执行；此前与预实验重叠的诊断文件保存在diagnostics_during_pilot。端到端运行未绑定CPU、未隔离Windows宿主负载，且开头少数运行与此前诊断重叠，因此只能作为描述性运行检查。42次均正常退出，41次采用模型；binary/lambda2/rep0无模型采用，不作为有效MC结果。

在本合成非平稳任务中，所有60次运行在目标切换后成功数均为0；每个rho仅3/10次在切换前获得过完整序列成功。该压力任务暴露了当前探索与累计启发式的局限，不能据此选择最优rho。

## 解释约束与下一步

T越大通常降低蒙特卡洛估计波动，但增加前向次数；lambda增大按公式单调提高选择分数，会减少过滤力度，其有效性必须由实际覆盖收益验证。全局挥发率只能控制信息素遗忘，不能清除启发式hits/tries的终身记忆；如果压力测试在奖励切换后恢复失败，就不能声称全局挥发已经解决非平稳适应问题。

当前rho=1e-4、T=8、lambda=1均保留为候选默认值，而非已证明最优值。正式论文参数选择应在独立验证目标上进行，固定配置后再测试六个基准，报告完整预算、独立轮数、覆盖率和开销，避免在测试集上选择最好参数。
